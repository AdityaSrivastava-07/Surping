# 🎵 SurPing

> A feature-rich web application built with **React** and **Vite**, combining a **Spotify-like music player experience** with a collection of fun and useful interactive tools.

---

## 🌟 Features

* **🎧 Music Player (Spotify Style):** Enjoy a sleek, modern music-playing interface inspired by Spotify, complete with playback controls and song lyric support.
* **🏓 Ping-Pong Game:** Take a quick break and play a built-in interactive arcade mini-game right inside the app.
* **📱 QR Code Generator:** Instantly generate custom QR codes for links, text, or data on the fly.
* **🌍 IP Locator:** Fetch real-time geolocation details and network info using external platform APIs.
* **🔌 API-Driven:** Seamlessly fetches required dynamic content and data from various third-party platform APIs.

---

## 🛠️ Tech Stack

* **Frontend Framework:** React (powered by Vite for ultra-fast builds and hot module replacement)
* **Styling:** Modern CSS / Component-based UI
* **Build Tool:** Vite
